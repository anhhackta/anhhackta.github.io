> Anime-inspired personal gallery — bright, playful, architectural, European flair

## Phong cách thiết kế

- **Anime + châu Âu**: Nền ấm (cream/peach), màu tươi (coral, teal, sunshine, lavender)
- **Kiến trúc đồ sộ**: Section rộng, typography lớn, grand serif (Fraunces)
- **Vui tươi**: Emoji, Pacifico cho accent, bouncy animations
- **Animation lồng nhau**: Parallax nhiều lớp, reveal theo scroll, stagger effects

## Công nghệ

- HTML5, CSS3 (Custom Properties, Grid, Flexbox)
- [GSAP](https://greensock.com/gsap/) + ScrollTrigger — scroll animations
- [Anime.js](https://animejs.com/) — micro interactions
- [Lenis](https://github.com/studio-freight/lenis) — smooth scroll
- [Font Awesome](https://fontawesome.com/) — icons
- Google Fonts: Fraunces (display), Poppins (body), Pacifico (fun)

## Sections

1. **Hero** — Sky gradient, clouds, building silhouettes, parallax layers
2. **About** — Portrait card với orbiting icons, tags, quote
3. **Skills** — 3 panels với animated progress bars
4. **Stats** — Counter animation trên coral band
5. **Journey** — Timeline 7 mốc với growing rail
6. **Projects** — 4 cards với 3D tilt hover
